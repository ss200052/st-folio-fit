# 满幅与悬浮滑块（st-folio-fit）

SillyTavern 插件。解决手机端聊天区左右留白、原生滚动条占位、头像挤占一列宽度的问题。

## 它做三件事

1. **聊天区彻底贴边**：把 `#sheld` 钉成 `100dvw`，压掉 `.mes` / `.mes_block` / `.mes_text` 的左右内边距，并关闭原生滚动条占位，右侧宽度归零。
2. **悬浮矩形滑块**：原生滚动条被关掉后，用一条自己画的矩形滑块代替。平时半透明（`opacity: .14`），手指移上去变亮（`.55`），按住拖动时最实（`.9`）并加宽。支持触摸与鼠标拖动。
3. **头像不再独占一列**：把 `.mesAvatarWrapper` 从消息左侧整列挪进「角色名 + 时间」那一行的最右端，缩成 22px 的小图标，正文因此可以使用整行宽度。

## 安装

在 SillyTavern 里：扩展（Extensions）→ Install extension → 粘贴本仓库地址 → 确认 → 刷新页面。

```
https://github.com/<你的用户名>/st-folio-fit
```

## 说明

- 与主题无关，滑块颜色取 ST 的 `--SmartThemeBodyColor`。
- 编辑消息时插件会跳过该条（不打断输入框）。
- 消息被重建（滑动切换、重新生成）后会自动重新归位头像。
- 酒馆顶栏的任意抽屉面板（接口、世界书、用户设置、背景、扩展、角色管理等）或侧边导航展开时，滑块自动收起；面板全部收起后自动回来。
- 兼容桌面与手机，逻辑按手机竖屏为基准。
